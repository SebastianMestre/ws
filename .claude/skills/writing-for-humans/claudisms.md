# Kill list

Scan the draft for these families. The ban is the move, not only the sample phrasing. Novel nouns in the same slot count.

Full catalog: https://claudisms.ai/ (CC0). Add entries when a phrase is a pattern, not a one-off.

## Announce value (cool-people rule)

Cut. Let the thing demonstrate itself.

- worth noting / worth talking about / worth sitting with / worth drawing / worth considering / any "worth \_\_\_"
- this matters / because it matters / and that matters
- the useful thing / here's the useful part
- the tell / that's the tell
- the right time / the right question / the right way / the right tool (questions containing "right" are fine)
- what I want you to see / what I want people to take away
- honestly / the honest version / an honest snapshot (on your own claim)
- useful as a frame ("the useful thing she does is")

## Pseudo-reflective journey

State the point. Do not narrate arriving at it.

- sit with / sitting with / a hard thing to sit with
- arriving at / keep arriving at
- coming back to / I keep coming back to / which brings me back to
- the question that keeps coming up / the question I keep coming back to
  ("What keeps coming up" as a bare opener is fine. The cleft is the tic.)
- the thread I didn't plan but can't unsee / I didn't set out to X, but / what I didn't expect to find
- here's where I landed / where I landed / here's where I come down
- what I keep running into / what I keep noticing / where I keep landing
- I can't stop thinking about
- the part that stayed mine
- stays yours / what stays yours / yours to keep
- what I'd leave you with / I'll leave you with
- nobody handed you that

## False peak

Present the thing. Do not crown it.

- the one that surprised me most / what struck me hardest / if I had to pick one
- the best thing you can do is / where X helps most / the one that [verb]
- the whole game / the whole [noun] / the entire [noun] / the only thing that matters
- the only thing that changed / the only X that [verb]
- what moved is / what actually moved / what changed is the
- hits hardest / lands hardest / strikes hardest
- most interesting / least interesting
- wreck / wrecked / shatter / obliterate / blow up (for a bounded effect)

## Writerly metaphor

Say the plain verb.

| Tic | Usually means |
|---|---|
| shape of | how it works, how it feels, the structure |
| lives (abstract) | is, happens, shows up |
| the engine | what works, the productive part |
| physics of | how it works, the conditions |
| names / naming that | says, spells out, or just state the consequence |
| quieter / louder (of an argument) | less explicit / more direct |
| load-bearing | important, required |
| hold / holding (a thought, a tension) | both are true, the rule it keeps |
| carry / carrying (an idea, a cost) | there are N costs; remember |
| moves / moving (an argument, attention) | the next section is about |
| points / pointing (evidence points toward) | state the conclusion |
| rides along | comes with, is attached |
| hands you / hands it back | gives, produces, returns |
| reaching for (gravitas, an effect) | wants, tries for |
| X is doing the work / heavy lifting | take the word out and nothing is left |
| in the chest / in my chest | name the feeling |
| bumped into | ran into |
| throughline | the connection, the recurring point |
| surface (verb) | show, raise, find |
| turns on (a sentence turns on) | depends on, is about |
| compounds / compounding (metaphor) | builds, adds up, grows |
| quietly (unnoticed change or sly refusal) | say what happened |
| settled / isn't settled / reopen a settled question | people disagree; we have not worked out X |
| hand-waving / waves it away | they never say how; the objection goes unanswered |

Literal physical sense of these words is fine.

## Punctuation and format

- Em dash (—). Use ` - `. Already-published em dashes need not be rewritten; do not add new ones.
- More than one dash-aside in one sentence
- Emojis anywhere in the piece
- `---` as a section divider (use headings)
- `**Bold term:** explanation` list pattern
- Four or more staccato sentences in a row
- A closing one-liner that restates the thesis
- Negative parallelism: "It's not just X, it's Y" / "Not only X, but Y" / "This isn't about X. It's about Y." / "No X. No Y. Just Z."

## Invented people and feelings

- most people / most people I've talked to / everyone I've worked with / a lot of folks / nobody I know (unless the observation is sourced)
- hit a nerve / struck a nerve / stuck with me / stayed with me / struck a chord / it really landed
- the thing that got me / what got me was / the thing that hooked me
- real / a real X / the real problem / the real thing (say measured, actual, or drop it)
- come along (too soft for a decision)
- quieter/louder as argument metaphors

## Spoken / dialogue extras

- Two speakers restating the same point in different words. One idea, one speaker, once.
- Sprinkled "um" / "uh" / "you know" / "right?" on short lines. Fillers only belong mid-passage in a long turn, and fewer is better.
- A synthetic voice claiming a human career. Disclose what it is.
- Crowned superlatives are worse aloud. Give the reason, not the crown.
